# Overview

Codee is an AI employee that works where you work. You don't need to adapt for (just a little) and it will work with the tools and you already use.

Codee is based on AI Agents such as Claude Code and Github Copilot. It does not try to reinvent what they already do best: working with code, context managing, MCP and other things. In the heart Codee has [skills](https://agentskills.io) system.

## Issue Trackers

Jira and Azure DevOps are now supported. Codee will pick up tasks from them and work on them.

Each work item status represents different skill. Codee runs skill for a specfic task like this `/story-developer TSK-4192`.

## Skills

Codee is based on skills. Some skills can be just an informative guidelines, while the others contain explicit intrstructions and commands on how to accomplish something ("actionable" skills).
Codee can be attached to a specific work item statuses and trigger specific "actionable" skills.

Codee extends common Agent Skills spec with itsown `x-codee-` prefixed fields in frontmatter.

For example:

```yaml
name: story-developer
description: Implement one subtask from an Issue Tracker story and submit a merge request.
disable-model-invocation: true
x-codee-trigger: issue
x-codee-issue-status: ['[AI] Ready for development', '[AI] In Progress']
x-codee-issue-type: story
argument-hint: <STORY_ID>
```

This means that this skill will be triggered on a work item with type `story` (`x-codee-issue-type`) in statuses `[AI] Ready for development` and `[AI] In Progress` (`x-codee-issue-status`).

Skills are located in the folder `.claude/skills` and can be checked in in your repo. They can be created/modified either as files with your favorite editor or in Codee UI.
